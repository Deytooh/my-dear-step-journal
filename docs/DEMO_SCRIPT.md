# Demo script

Target approximately three minutes; this is an editing target, **not an official portal limit**. Verify the logged-in submission form. Use fictional records and an owned meal photo, not real health data.

## Preparation

Follow SETUP_AND_ENV: configure key/model/quota/private bucket, run the live smoke test and test account separation. Use a disposable guest profile for the visible example home, and a separate dedicated signed-in test account for paid AI. Prepare a fictional purchase/stock lot in that test account if inventory is shown. The guest demo anchor is the displayed local Seoul date at reset. Record the anchor in the recording notes. Keep exact source inputs visible; no prerecorded fallback disguised as live inference.

| Time | Screen action | Suggested narration |
| --- | --- | --- |
| 0:00–0:20 | Today: labeled guest examples, latest weight, user-set schedule, product-specific stock | “My Dear Step is a personal journal that reduces typing while keeping records inspectable.” |
| 0:20–0:35 | One-tap water answer, Undo, then Quick Add | “Fast manual logging works independently of AI. Undo reverses this entry and question state without removing later work.” |
| 0:35–1:20 | In the dedicated test account, paste the fictional Korean sentence from SETUP_AND_ENV; consent; extract; expand drafts | “Momo uses Meta Muse Spark Open through Baseten. It proposes several editable records and keeps unknown dose, site and clock time unknown.” |
| 1:20–1:40 | Correct one value/date; confirm once; show device versus account status; reload and open source | “Confirmation accepts the log, not an AI claim of medical truth. The source and correction remain visible.” |
| 1:40–2:20 | Meal → owned photo → consent/analyze → edit portion and estimate → select half → confirm | “Food identification and energy are estimates. We compute item totals in code and apply the amount I explicitly chose once. An unknown item makes the total partial.” |
| 2:20–2:40 | Calendar/history → reopen saved meal and photo/source | “This is part of one journal, with the same dates, editing and private storage as other entries.” |
| 2:40–3:00 | Journey finder → ask for the logged meal/moment; open original; show export | “Memory returns existing dated records, never invented events. Manual keyword search remains available if AI is unavailable.” |

Finish: “Multimodal capture, editable records, durable evidence and personal history—without treatment advice or nutrition targets.”

## Short fallback (60–90 seconds)

Show Today → manual meal with photo and an explicitly user-entered estimate → half-portion calculation → source after reload → calendar/history → export. If the live provider is unavailable, state that clearly and show the implemented manual fallback. This fallback does **not** establish the required runtime Meta use for submission; record the live portion only after configuration works.

## Record honestly

- No medication recommendations, causal chart claims, meal grades, calorie budgets or fake integrations.
- “Browser voice transcription,” not native audio-to-Meta.
- “In-app user-set schedule,” not background notifications.
- “Photo estimate,” not measured calories or a confidence interval.
- Repo/video/live-app URLs must be filled from actual accessible destinations.
