# Three-minute demo script

Show one complete journey: **capture → review → correct → confirm → reopen the source**. Use fictional records and an owned photo, never real health information. The [official rules](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/waiver), checked on 4 November 2026, require a three-minute demo video. Keep the finished recording within three minutes and verify the portal's upload fields before submitting.

## Recording preflight

- Follow [SETUP_AND_ENV](SETUP_AND_ENV.md). A dedicated test account, configured Meta provider, quota and private photo storage must pass the live smoke test first. Local fixtures and mocked tests are not live Meta evidence.
- Open the actual build to be shown. Choose the presentation language, complete or skip onboarding and wait for account sync. Check the visible date/timezone before using “today” or “yesterday.”
- Prepare one owned meal photo and this fictional caption. Do not promise a particular model output. If it misses a fact, visibly correct it or add a missing entry.

> Fictional demo. Today I weighed 78.2 kg. This photo is my lunch, and I ate half. Yesterday evening I had an injection, but I do not remember the medication, dose or site.

- Rehearse the selected-entry count, one correction and the source after reload. Keep purchase management, search, charts and exports out of the main story.

The model label is the **requested configuration**, not a provider-confirmed identity. “Analyzed at” is the app-recorded timestamp displayed in the journal's timezone. Neither label certifies a live call or a medical result. A provider delay must not be hidden by substituting a fixture for its output.

## Honest fallback

If live AI is unavailable, state that immediately. Show manual meal entry with the owned photo, a clearly user-entered estimate, explicit half portion, save, reload and source. This demonstrates the manual path only. It does **not** establish live Meta use or replace the required provider smoke test.

If the source changes after organizing, organize again before confirming. If saving or syncing fails, show the actual retry/recovery action; do not call the entry synced. Back up before choosing between conflicting versions.

## Off-camera checks

- Rehearse at 360/390/430 px and on the actual phone with keyboard and enlarged text. Browser emulation is not a device test.
- For voice, use fictional phrases: pause and resume five times, include an intentional repetition, finish, then edit during a pause. Confirm no duplicated phrase or overwritten correction, and that switching away stops the microphone. Voice is browser transcription, not raw-audio Meta inference.
- Guest examples use the visible date in the journal’s selected timezone at reset and must stay in a disposable profile. Reset is destructive to that guest journal after confirmation.
- Do not claim treatment benefits, measured calories, background notifications, deployed security certification or a guaranteed judging score. Use real, accessible repository/app/video links only.
